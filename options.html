    Connect Ollama

    1. Allow this extension. Until you do, Ollama rejects it with error 403.

      Linux

      On Linux, open the service settings:

      sudo systemctl edit ollama

      Write this at the top, save, and restart Ollama:

      [Service]
Environment="OLLAMA_ORIGINS=chrome-extension://…"
      sudo systemctl restart ollama
      Windows / macOS

      On Windows or macOS, create this environment variable and restart Ollama:

      OLLAMA_ORIGINS=chrome-extension://…

    2. Download a model and choose it below, for example:

      ollama pull gemma4:12b

    With less than 24 GB of graphics memory, Ollama reads only 4096 tokens per request and silently drops the rest. That's why 1500 characters are sent at a time (Advanced → Speed). To send more, add Environment="OLLAMA_CONTEXT_LENGTH=8192" under the permission and restart Ollama: it uses more graphics memory.
